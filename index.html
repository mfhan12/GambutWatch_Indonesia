GambutWatch Indonesia

Pantau titik api di lahan gambut Sumatra dan Kalimantan pada peta satelit. Zoom sampai terlihat jalan dan desa, klik titik di peta untuk jarak ke titik api terdekat, lalu laporkan kejadian di sekitarmu. Tanpa login.

Data di halaman ini adalah contoh simulasi untuk 9 wilayah gambut di Sumatra dan Kalimantan. Klik Aktifkan data langsung untuk menarik titik api NASA FIRMS dan cuaca Open-Meteo.
